VOIDRUN

Can a computer learn to dodge better than you?

This Introduction to Machine Learning project asks whether a Genetic Algorithm (GA) can evolve a rocket controller that dodges better. It selects successful pilots, combines their neural-network controls, and mutates them across generations.

You’ll fly first, meet a brand-new pilot, then help it learn and see if it can beat your best run.

Academic Architecture & Defense Guide

HOW IT WORKS // SCIENTIFIC OVERVIEW

1. CORE RESEARCH CONCEPT

This project investigates autonomous multi-threat evasion within bounded 2D dynamical environments using Neuroevolution (Genetic Algorithms optimizing Feedforward Artificial Neural Networks). Rather than computing explicit gradient descent (backpropagation), the genetic algorithm optimizes neural network connection weights through evolutionary selection, reproduction, and stochastic mutation.

2. NEURAL NETWORK SENSORY PERCEPTION

The rocket controller is a Multi-Layer Perceptron (MLP) with 20 normalized input features, 16 hidden neurons (with tanh non-linear activations), and 4 output units (logistic sigmoid) representing directional thrust vectors.

Input Vector [20]:
• Rocket Normalized Position (x, y) & Velocity (vx, vy) [4]
• Normalized Clearances to Arena Boundaries (Left, Right, Top, Bottom) [4]
• 8-Directional 360° Proximity Radar Rays (d1 .. d8 ∈ [0, 1]) [8]
• Nearest Threat Relative Vector (Δx, Δy), Distance & Relative Velocity [4]

Output Vector [4] → Throttle: X = out[1] - out[0], Y = out[3] - out[2] ∈ [-1.0, 1.0]

3. MATHEMATICAL FITNESS FORMULATION

Fitness balances pure survival time with active tactical evasion, while explicitly penalizing passive wall camping and erratic control jitter:

Fitness = wtime · Tsurvival + wdodge · Nnear_misses + wwave · Wbonus
             - wwall · Twall_hug - whit · Nwall_hit - wjitter · Jjitter

This formulation eliminates trivial exploit loops (such as sitting motionless in corners) and encourages dynamic centering and proactive hazard dodging.

3B. ADAPTIVE ARENA & AI VISIBILITY MODES

Adaptive Arena Director: A rule-based game design system (completely decoupled from the machine learning models) that detects repetitive player habits—such as edge camping, circular looping, or stationary stagnation—and triggers telegraphed flushing waves (e.g. edge sweeps or crossfire pins) with advance warnings.

AI Visibility Modes: The interface provides an instant, seamless toggle between Game View (clean arcade graphics) and AI Insight (visualizing the controller's exact 180px radar scan, primary hazard trajectory, and chosen throttle action vector in real time without interrupting the run).

4. FIVE-SLIDE COLLEGE PRESENTATION OUTLINE

SLIDE 1
1. Problem Statement
  • Challenge: Real-time autonomous navigation and collision avoidance in bounded environments with unpredictable, multi-directional dynamic hazards.
  • Objective: Develop an autonomous neuro-controller using Genetic Algorithms that learns evasive maneuvers without hand-crafted heuristics or human demonstrations.
  • Research Question: How effectively can neuroevolution evolve evasion policies that outperform random actions and compete against classical potential-field algorithms?
SLIDE 2
2. Methodology
  • Sensory Space: Compact 20-dimensional normalized observation vector (spatial position, velocities, boundary proximity, 8-ray omnidirectional radar, and nearest hazard trajectory).
  • Controller Architecture: 20 → 16 → 4 feedforward network (404 evolvable weights and biases) with hyperbolic tangent activations.
  • Evolutionary Operators: Elitism (preserving top 2 controllers), Tournament Selection (k=3), Uniform Crossover, and Additive Gaussian Mutation (σ = 0.25).
  • Reproducibility: Everyone in a generation faces the same repeatable hazard pattern; the pattern changes each generation. Separate comparisons use five shared test patterns.
SLIDE 3
3. Research Paper
  • Domain: Evolutionary Robotics & Neuroevolution of Augmenting Topologies (NEAT / Genetic Algorithms for Control).
  • Experimental Setup: Comparing three controller paradigms across 5 identical unseen test seeds: Random Walk, Artificial Potential Fields (Repulsion Heuristic), and Evolved GA Neuro-Controller.
  • Paper Structure: Introduction → Dynamical System Modeling → Sensory Encoding & GA Formulation → Empirical Ablations & Results → Limitations & Conclusion.
SLIDE 4
4. Result
  • Training progress: Show the actual best and average fitness values from the Evolution Lab.
  • Comparison: Report measured survival and score for the random, rule-based, and evolved pilots across the same test patterns.
  • Observation: Describe movement patterns you saw in the replay; avoid claiming a behavior unless it is visible in your results.
SLIDE 5
5. Conclusion
  • Key Finding: Genetic algorithms successfully synthesize effective non-linear reactive controllers for multi-hazard evasion without backpropagation or labeled datasets.
  • Scientific Limitations: Evolved controllers are bounded by the 2D kinematics and hazard distribution patterns of the simulation, with potential seed overfitting if generation diversity drops.
  • Future Scope: Extending to 3D celestial navigation, variable threat physics, and hybrid Neuroevolution-Reinforcement Learning (PPO/DQN) paradigms.
